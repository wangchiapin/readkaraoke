# readkaraoke｜朗讀反紅

輸入中文、用空格分詞，按開始後每個詞依序變紅，並顯示台灣讀音拼音或注音。搭配 iPhone 螢幕錄影，跟著紅字念就能錄成影片傳給學生。

網址：https://wangchiapin.github.io/readkaraoke/

原始檔與說明在 `src/`。

## 怎麼用

1. 在輸入框貼上中文，詞和詞之間用空格隔開（例：`我 是 學生，你 呢？`）。可按「範例」「清除」，也能一鍵「轉成繁體」「转成简体」。
2. 選拼音或注音；預覽會顯示分好的詞和讀音。讀音不對時，點那個字可換讀音，或用「自訂讀音規則」。
3. 設定每個詞停留幾秒（依字數 1／2／3／4 字以上分開設）、標點後和換行後多停幾秒、開始前倒數幾秒。
4. 顯示設定：字級、楷體或黑體、單色或依聲調上色、浮水印。
5. 按「開始」先倒數，然後全螢幕播放，每個詞依序變紅（念過的保持紅色），播完停在全紅，可「再播一次」或「回到編輯」。
6. 開始前先開 iPhone 螢幕錄影，就能錄成影片傳給學生。

## 浮水印

只在播放畫面出現（停止播放就隱藏），預設是「不要」。可選「固定右下角」或「隨機移動」（每 3 秒淡出換位置，只放在沒有字的空白處）；文字可自訂，預設是 IG 帳號。錄影時用來標示出處。

## 檔案結構

- `index.html`：網站本體（由 `src/` 組合出來的單一檔案，不要直接改它）。
- `opencc-cn2t.js`：第三方的簡體→繁體字庫，按「轉成繁體」時才載入。
- `src/`：原始檔、分詞與計時規則、組合方式，詳見 `src/README.md`。讀音引擎與 messagewithpinyin 共用同一套。
- 設定與輸入內容只存在使用者自己的瀏覽器，沒有後端。
